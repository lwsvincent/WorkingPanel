## 🎯 核心功能示範

### 1. 建立任務
1. 點擊象限 `+` 按鈕
2. 填寫表單資料
3. 點擊「建立」
4. 任務卡片即時出現

### 2. 拖曳移動
1. 按住任務卡片拖曳
2. 目標象限顯示藍色高亮
3. 釋放滑鼠完成移動
4. 任務自動更新象限

### 3. 標籤篩選
1. 點擊頂部標籤徽章
2. 只顯示含該標籤的任務
3. 可多選標籤 (OR 邏輯)
4. 再次點擊取消篩選

### 4. 完成任務
1. 勾選任務核取方塊
2. 任務移至完成區域
3. 取消勾選可恢復
4. 自動回到原象限

### 5. 匯出/匯入
1. 點擊「匯出」下載 JSON
2. 點擊「匯入」選擇檔案
3. 選擇覆蓋或合併模式
4. 資料即時更新

## 📝 開發紀錄

### 技術決策
1. **選擇 @dnd-kit**: 輕量、TypeScript 友好、效能優異
2. **Tailwind CSS**: 快速開發、零配置、樹搖優化
3. **Context + Reducer**: 中等複雜度狀態管理的最佳方案
4. **localStorage**: 簡單可靠、無需後端、開發快速

### 遇到的挑戰與解決
1. **Tailwind PostCSS 更新**
   - 問題: `tailwindcss` 套件分離
   - 解決: 安裝 `@tailwindcss/postcss`

2. **TypeScript verbatimModuleSyntax**
   - 問題: 類型匯入需明確標示
   - 解決: 使用 `import type` 語法

3. **Checkbox onChange 類型**
   - 問題: MouseEvent vs ChangeEvent
   - 解決: 簡化為無參數函數
