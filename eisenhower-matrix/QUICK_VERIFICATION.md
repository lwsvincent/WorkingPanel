# 快速驗證指南 (5 分鐘)

這是一個快速測試指南,可在 5 分鐘內驗證所有核心功能。

## 🚀 開始前準備

1. 開啟瀏覽器: http://localhost:5174/ (開發模式)
   或 http://localhost:4173/ (生產預覽)

2. 打開瀏覽器開發者工具 (F12)
   - 檢查 Console 是否有錯誤 ❌
   - 應該看不到任何錯誤訊息 ✅

---

## ⚡ 快速測試 (按順序執行)

### 1️⃣ 介面載入測試 (30 秒)
- [ ] 看到標題「艾森豪矩陣」
- [ ] 看到 4 個象限 (2x2 網格)
  - 緊急+重要 (左上,紅色邊框)
  - 不緊急+重要 (右上,藍色邊框)
  - 緊急+不重要 (左下,黃色邊框)
  - 不緊急+不重要 (右下,灰色邊框)
- [ ] 看到底部「已完成」區域
- [ ] 每個象限右上角有 `+` 按鈕

**✅ 通過標準**: 畫面清晰,無版面錯誤

---

### 2️⃣ 建立任務測試 (1 分鐘)
1. 點擊「緊急+重要」的 `+` 按鈕
2. 填寫:
   - 標題: `測試任務 1`
   - 內容: `這是測試內容`
   - 標籤: 輸入 `工作` 按 Enter,輸入 `重要` 按 Enter
   - 截止日期: 選擇今天
3. 點擊「建立」

- [ ] 彈窗關閉
- [ ] 象限中出現新任務卡片
- [ ] 卡片顯示標題、內容、2 個標籤、日期
- [ ] 截止日期顯示「今天」且為橙色

**✅ 通過標準**: 任務卡片正確顯示所有資訊

---

### 3️⃣ 快速建立多個任務 (1 分鐘)
在不同象限各建立 1 個任務:

**不緊急+重要** (點 `+` 建立)
- 標題: `學習新技術`
- 標籤: `學習`

**緊急+不重要** (點 `+` 建立)
- 標題: `回覆郵件`
- 標籤: `溝通`

**不緊急+不重要** (點 `+` 建立)
- 標題: `整理桌面`

- [ ] 4 個象限各有至少 1 個任務
- [ ] 所有任務都正確顯示

**✅ 通過標準**: 各象限都有任務卡片

---

### 4️⃣ 拖曳功能測試 (30 秒)
1. 按住「測試任務 1」不放
2. 拖曳到「不緊急+重要」象限
3. 釋放滑鼠

- [ ] 拖曳時卡片半透明
- [ ] 目標象限變成淡藍色
- [ ] 釋放後任務出現在新象限
- [ ] 原象限任務消失

**✅ 通過標準**: 任務成功移動到新象限

---

### 5️⃣ 完成任務測試 (20 秒)
1. 勾選「測試任務 1」的核取方塊

- [ ] 任務移動到底部「已完成」區域
- [ ] 完成區域顯示「(1 個任務)」
- [ ] 標題有刪除線
- [ ] 取消勾選後任務回到原象限

**✅ 通過標準**: 完成/取消完成正常運作

---

### 6️⃣ 編輯任務測試 (30 秒)
1. 點擊任一任務卡片主體 (不是核取方塊)
2. 修改標題為 `已編輯的任務`
3. 點擊「更新」

- [ ] 彈窗打開,顯示原有資料
- [ ] 可以修改所有欄位
- [ ] 更新後卡片顯示新標題

**✅ 通過標準**: 編輯功能正常

---

### 7️⃣ 刪除任務測試 (20 秒)
1. 點擊任一任務的 `⋮` 按鈕
2. 選擇「刪除」
3. 點擊確認

- [ ] 顯示選單 (編輯/刪除)
- [ ] 彈出確認對話框
- [ ] 確認後任務消失

**✅ 通過標準**: 刪除功能正常

---

### 8️⃣ 標籤篩選測試 (30 秒)
1. 看頂部標籤篩選區 (應該有 `工作`, `重要`, `學習`, `溝通` 等)
2. 點擊「工作」標籤

- [ ] 只顯示有「工作」標籤的任務
- [ ] 其他任務消失
- [ ] 「工作」標籤有藍色環 (選中狀態)
- [ ] 再次點擊取消篩選,所有任務恢復

**✅ 通過標準**: 篩選正確運作

---

### 9️⃣ 匯出功能測試 (20 秒)
1. 點擊頂部「匯出」按鈕

- [ ] 自動下載 JSON 檔案
- [ ] 檔案名稱格式: `eisenhower-tasks-2026-01-06.json`
- [ ] 打開檔案可看到 JSON 格式的任務資料

**✅ 通過標準**: 成功下載 JSON 檔案

---

### 🔟 localStorage 持久化測試 (30 秒)
1. 重新整理頁面 (F5)

- [ ] 所有任務仍然存在
- [ ] 任務位置保持不變
- [ ] 篩選狀態重置
- [ ] 開啟 DevTools > Application > Local Storage
- [ ] 看到 `eisenhower-matrix-tasks` 鍵

**✅ 通過標準**: 資料成功保存並恢復

## 🐛 如果遇到問題

### 常見問題排查

#### 1. 樣式錯亂/沒有顏色
```bash
# 檢查 Tailwind 是否正確載入
# 在 DevTools > Network 看是否有 CSS 檔案
# 應該看到 index-*.css
```

#### 2. 拖曳不工作
```bash
# 檢查 Console 是否有錯誤
# 檢查滑鼠是否移動超過 8px (激活距離)
```

#### 3. localStorage 不保存
```bash
# 檢查瀏覽器隱私模式
# 檢查 localStorage 是否被禁用
# 在 DevTools > Application > Local Storage 查看
```

#### 4. 建構失敗
```bash
cd eisenhower-matrix
rm -rf node_modules
npm install
npm run build
```
