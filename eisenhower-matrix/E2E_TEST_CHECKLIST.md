# E2E 測試檢查清單

## 開發伺服器
- ✅ 伺服器運行中: http://localhost:5174/
- ✅ Tailwind CSS 正確載入
- ✅ 無建構錯誤

## 測試步驟

### 1. 初始載入測試
- [ ] 開啟 http://localhost:5174/
- [ ] 檢查四個象限是否正確顯示
  - 緊急 + 重要 (紅色邊框)
  - 不緊急 + 重要 (藍色邊框)
  - 緊急 + 不重要 (黃色邊框)
  - 不緊急 + 不重要 (灰色邊框)
- [ ] 檢查頂部篩選工具列
- [ ] 檢查底部完成區域（可摺疊）

### 2. 建立任務測試
- [ ] 點擊「緊急 + 重要」象限的 `+` 按鈕
- [ ] 填寫表單：
  - 標題: "測試任務 1"
  - 內容: "這是一個測試任務的內容描述"
  - 標籤: 輸入 "工作" 並按 Enter
  - 標籤: 輸入 "重要" 並按 Enter
  - 截止日期: 選擇今天
- [ ] 點擊「建立」按鈕
- [ ] 檢查任務卡片是否出現在象限中
- [ ] 檢查任務卡片顯示：
  - ✓ 標題正確
  - ✓ 內容預覽（截斷）
  - ✓ 標籤顯示（不同顏色）
  - ✓ 截止日期顯示為「今天」（橙色）

### 3. 重複建立多個任務
在不同象限建立以下任務：

**緊急 + 重要**
- [ ] "處理緊急客戶問題" - 標籤: 工作, 緊急 - 截止: 今天

**不緊急 + 重要**
- [ ] "規劃下季度目標" - 標籤: 規劃, 工作 - 截止: 7天後
- [ ] "學習新技術" - 標籤: 學習, 個人

**緊急 + 不重要**
- [ ] "回覆電子郵件" - 標籤: 溝通 - 截止: 今天

**不緊急 + 不重要**
- [ ] "整理桌面檔案" - 標籤: 雜務

### 4. 編輯任務測試
- [ ] 點擊任一任務卡片主體
- [ ] 修改標題
- [ ] 新增/移除標籤
- [ ] 修改截止日期
- [ ] 點擊「更新」
- [ ] 檢查變更是否反映在卡片上

### 5. 拖曳功能測試
- [ ] 拖曳「緊急 + 重要」的任務到「不緊急 + 重要」
- [ ] 檢查任務是否移動到新象限
- [ ] 拖曳時觀察：
  - ✓ 半透明預覽
  - ✓ 目標象限高亮顯示（藍色背景）
- [ ] 跨多個象限測試拖曳

### 6. 完成任務測試
- [ ] 勾選任一任務的核取方塊
- [ ] 檢查任務是否移動到「完成區域」
- [ ] 檢查完成區域計數器更新
- [ ] 取消勾選完成區域的任務
- [ ] 檢查任務是否移回原象限

### 7. 篩選功能測試
- [ ] 點擊頂部的「工作」標籤
- [ ] 檢查只顯示帶有「工作」標籤的任務
- [ ] 點擊「學習」標籤（多選）
- [ ] 檢查顯示「工作」或「學習」的任務
- [ ] 取消所有標籤篩選
- [ ] 檢查所有任務恢復顯示

### 8. 顯示/隱藏完成任務
- [ ] 取消勾選「顯示已完成」
- [ ] 檢查完成區域是否隱藏
- [ ] 重新勾選
- [ ] 檢查完成區域恢復顯示

### 9. 刪除任務測試
- [ ] 點擊任務卡片右上角的 `⋮` 按鈕
- [ ] 選擇「刪除」
- [ ] 確認刪除對話框
- [ ] 檢查任務是否被刪除

### 10. 匯出功能測試
- [ ] 點擊頂部「匯出」按鈕
- [ ] 檢查是否下載 JSON 檔案
- [ ] 檔案名稱格式: `eisenhower-tasks-YYYY-MM-DD.json`
- [ ] 用文字編輯器打開檔案檢查格式

### 11. 匯入功能測試
- [ ] 建立 2-3 個新任務
- [ ] 點擊「匯入」按鈕
- [ ] 選擇之前匯出的 JSON 檔案
- [ ] 選擇「確定」（覆蓋模式）
- [ ] 檢查任務被替換為匯入的任務
- [ ] 再次匯入，選擇「取消」（合併模式）
- [ ] 檢查任務數量增加（合併）

### 12. localStorage 持久化測試
- [ ] 建立幾個任務
- [ ] 重新整理頁面（F5）
- [ ] 檢查所有任務是否保留
- [ ] 開啟開發者工具 > Application > Local Storage
- [ ] 檢查 `eisenhower-matrix-tasks` 鍵是否存在

### 13. 截止日期視覺提示測試
建立任務測試不同狀態：
- [ ] 已過期任務（設定昨天的日期）
  - ✓ 紅色左邊框
  - ✓ 紅色文字「逾期 X 天」
- [ ] 今天到期
  - ✓ 橙色左邊框
  - ✓ 橙色文字「今天」
- [ ] 未來到期
  - ✓ 灰色文字「X 天後」

### 14. 完成區域摺疊測試
- [ ] 點擊完成區域標題
- [ ] 檢查區域收起
- [ ] 再次點擊
- [ ] 檢查區域展開

### 15. 標籤顏色一致性測試
- [ ] 建立多個任務使用相同標籤
- [ ] 檢查所有相同標籤顏色一致
- [ ] 在篩選工具列檢查標籤顏色一致

### 16. 響應式測試（基本）
- [ ] 調整瀏覽器視窗寬度
- [ ] 檢查最小寬度 1024px 限制
- [ ] 檢查象限保持 2x2 網格

### 17. 極端情況測試
- [ ] 建立沒有標籤的任務
- [ ] 建立沒有內容的任務（只有標題）
- [ ] 建立沒有截止日期的任務
- [ ] 建立標題達到 100 字限制
- [ ] 建立內容達到 500 字限制
- [ ] 單一象限建立 10+ 個任務（測試滾動）

### 18. 錯誤處理測試
- [ ] 嘗試建立空標題任務
- [ ] 檢查是否顯示錯誤提示「請輸入任務標題」
- [ ] 匯入無效的 JSON 檔案
- [ ] 檢查是否顯示錯誤訊息
